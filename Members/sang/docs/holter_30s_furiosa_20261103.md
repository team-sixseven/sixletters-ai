# Furiosa 30초 구간 연구용 실험

## 대상과 절차

파형 화면에서 기본 선택된 원본 개발 환자 한 명의 X 유도, 기록 시작 후 0~30초를 사용했다. 200Hz 원본 6,000개 샘플과 30초 품질 인덱스 통과 상태를 확인했다. 이는 선택된 한 구간에 대한 탐색 결과이며 전체 환자나 24시간 전 구간 평가가 아니다.

NeuroKit2로 R파를 검출하고 RR 평균·표준편차·RMSSD 추정치와 심박수 등의 제한된 요약을 생성했다. 해당 요약만 Furiosa 서버의 네 LLM에 전달했다. **원본 파형 이미지·T파 위치·정답 라벨은 모델에 전달하지 않았다.** 정상박동 분류와 R파 정확도는 검증되지 않았다.

각 모델에는 0~100의 연구용 검토 우선순위 점수를 요청했다. 이 점수는 임의적이고 보정되지 않았으며 SCD 위험 확률, 부정맥 진단, 실제 위험 구간 판정, 임상 알림 기준이 아니다. 모델 간 점수가 공통 척도라는 근거도 없다.

## 화면과 검증

30초 파형·품질 인덱스는 로컬 화면에서 확인한다. 결과는 환자·시작 시각·유도가 모두 일치할 때만 표시되고 다른 구간에는 표시하지 않는다. 6,000개 API 샘플이 원본 NPY와 일치하는 것을 확인했다. NPU에서 4개 모델 모두 정상 종료했다. QT 및 T파 끝 후보는 공개 QTDB의 소규모 확인에서 큰 오차가 있어 기본 비활성화되어 있고 본 LLM 분석의 일부가 아니다.

기존 356명 비교를 착오로 시작했다가 범위 정정 후 중단했으며 해당 부분 결과는 STOPPED로 기록하고 이번 결과에 사용하지 않았다.
