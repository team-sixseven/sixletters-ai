# Furiosa LLM 3종 추가 비교

## 설계

기존 Qwen3-32B-FP8와 [GPT-OSS-20B](https://developer.furiosa.ai/v2026.4.0/en/furiosa_llm/models/gpt-oss.html), [Qwen3-30B-A3B-Instruct-2507-FP8](https://huggingface.co/furiosa-ai/Qwen3-30B-A3B-Instruct-2507-FP8), [EXAONE-4.0-32B-FP8](https://huggingface.co/furiosa-ai/EXAONE-4.0-32B-FP8)를 Furiosa NPU에서 비교했다. EXAONE은 비상업적 사용 조건을 포함하므로 사용 전 모델 라이선스를 확인한다.

기존 train+validation 356명(양성 40명, 음성 316명)을 환자 단위 층화 5-fold(seed 42)로 나누어 동일 환자·입력·조건별로 평가했다. 원본 test 89명은 이번 예측에 사용하지 않았다. 사례 조건은 평가 환자의 나머지 fold에서 임상 특징 거리로 양성 2명과 음성 2명을 선택했다. 거리 표준화도 나머지 fold에서만 적합했다. LLM을 환자 데이터로 미세조정하지 않았다. 모델마다 각 조건 356/356건 성공했고 예측 비교에서 환자 356명이 모두 짝지어졌다.

조건은 Holter 요약만, 임상만, Holter+임상, Holter+임상+사례다. 임상 단독에도 과거 실험과 같은 시스템 프롬프트의 Holter 문구가 남으며 ECG 요약은 null이다. 공통 temperature 0, 최대 1024 토큰, 위험도 JSON 스키마를 사용했다. GPT-OSS는 low reasoning 설정과 JSON 제약, Qwen3-30B는 비추론 Instruct, Qwen3-32B와 EXAONE은 thinking 비활성화로 실행했다. 모델별 템플릿·양자화·장치 수가 달라 성능 차이를 구조 하나만의 효과로 해석할 수 없다.

## 전체 예측의 AUROC / AP

| 모델 | Holter | 임상 | Holter+임상 | Holter+임상+사례 |
|---|---:|---:|---:|---:|
| Qwen3-32B (기존) | 0.483 / 0.107 | 0.759 / 0.288 | 0.691 / 0.207 | 0.699 / 0.267 |
| GPT-OSS-20B | 0.414 / 0.100 | 0.582 / 0.188 | 0.510 / 0.140 | 0.642 / 0.239 |
| Qwen3-30B-A3B | 0.595 / 0.142 | 0.719 / 0.268 | 0.669 / 0.185 | 0.721 / 0.232 |
| EXAONE-4.0-32B | 0.527 / 0.122 | 0.735 / 0.305 | 0.735 / 0.219 | 0.612 / 0.143 |

AP는 양성 비율이 낮을 때 참고할 정밀도-재현율 요약이다. 이 집단의 양성 비율은 40/356 = 0.112다. AUROC가 높아도 위험도 값이 보정되었거나 특정 문턱에서 환자를 잘 찾는다는 뜻은 아니다.

## 해석과 한계

- 임상 단독 AUROC는 기존 Qwen3-32B가 0.759로 가장 높았고 EXAONE은 0.735, Qwen3-30B는 0.719였다. EXAONE의 임상 단독 AP 0.305는 기존 모델의 0.288보다 높다. 모델 간 작은 차이를 확정적인 우열로 볼 수 없다.
- Qwen3-30B의 Holter 단독 AUROC는 기존 모델보다 0.112 높았지만 AP는 0.142였고, 50% 문턱에서는 양성 40명을 모두 놓쳤다. EXAONE의 Holter+임상 AUROC 0.735도 같은 문턱에서 양성 1명만 탐지했다.
- 사례 추가 효과는 모델에 따라 다르다. Qwen3-30B의 Holter+임상 사례 조건은 AUROC 0.721 및 양성 15/40 탐지였으나, EXAONE은 사례를 넣었을 때 AUROC가 0.735에서 0.612로 낮아졌고 양성 0/40 탐지였다. 사례의 2:2 구성은 실제 유병률을 반영하지 않는다.
- 환자와 양성 수가 작고 이미 반복해서 살펴본 개발 자료이므로 탐색 결과다. 원본 test 성능을 추정하지 않으며, 외부 검증도 없다. 환자 정보의 측정 시점, RR/HRV 요약 품질과 결측 등은 [이전 진단 기록](furiosa_holter_diagnostics_20261102.md)을 참고한다. 원시 파형 전체를 LLM에 넣은 비교가 아니다.
- LLM을 바꾸면 결과가 달라질 수 있지만 이번 세 모델에서 모든 조건을 일관되게 크게 개선한 모델은 확인되지 않았다. 이 결과만으로 원인이 데이터 품질이라고 단정할 수도 없다. 의료적 의사결정에 사용하지 않는다.
