# Holter RR 기반 GPT 실험: 계산과 검증 상태

## 대상과 목적

이 실험은 기존 파형 일반 통계 대신 전체 가용 Holter 파형의 R파와 RR 간격으로 심박·HRV·감속 능력의 연구용 추정치를 생성한다. 현재 `Members/sang/datas/Holter`의 `final_split_augmented.csv`에서 원본 train 285명과 validation 71명만 선택한다. test 89명과 증강 복사본은 제외한다. 다른 PC의 653명/개발 564명 코호트, 해당 코호트의 fold 및 성능 수치와 동일하지 않다.

정답 라벨과 환자 ID는 로컬 평가·파일에서만 사용하고 GPT에 전송하지 않는다. 원본 PhysioNet 공개 파일에서 개발 환자의 Holter 리듬과 참고 HRV 값만 추려 로컬에 두었다. 참고 HRV는 로컬 품질 비교에만 쓰고 API에 보내지 않는다. 이 CSV는 개인별 데이터이므로 Git 제외 경로에 둔다.

## 구현한 계산과 가정

- 200 Hz, 30초 품질 인덱스 및 유도 메타데이터는 기존 `basic.yaml`을 따른다. 제외 구간은 사용하지 않는다. NeuroKit2로 유도별 5분 청크에 전후 문맥을 붙여 R파를 검출한 뒤 중복 경계 검출을 제거한다. 이용 가능한 유도 중 그럴듯한 박동 수를 가진 구간 비율과 생리적 RR 비율을 기준으로 선택한다. 이 선택법은 별도 주석 데이터로 검증되지 않았다.
- 300~2000 ms 범위와 직전 간격 대비 20% 변화 기준으로 RR을 걸러낸다. 이는 조기수축을 분류하는 방법이 아니며 진짜 정상-정상(NN) 간격을 보장하지 않는다. 제외된 간격이나 품질 구간을 사이에 두고 RMSSD, pNN50, PRSA를 연결하지 않는다.
- 평균 심박수는 필터된 평균 RR의 역수이고, 시간별 극값은 한 시간에 유효 간격이 50% 이상인 구간만 사용한다. SDNN은 필터된 RR의 표본 표준편차, SDANN은 유효 간격이 80% 이상인 5분 구간의 평균 RR에 대한 표본 표준편차다. RMSSD와 pNN50은 연속된 유효 간격 차이로 계산한다. 50%·80%는 누락 구간 영향 완화를 위한 **실험적 가정**이지 1996 표준에서 정한 기준이 아니다.
- 감속 능력은 RR이 앞 간격보다 길어지는 지점의 연속된 네 RR을 정렬하여 `(RR[i] + RR[i+1] - RR[i-1] - RR[i-2]) / 4`를 평균낸 4점 PRSA 추정이다. 여기서 i는 RR[i]가 RR[i-1]보다 긴 기준점이다. 결측과 제거 간격을 가로지르지 않는다. Bauer 원 논문의 모든 전처리 조건과 동등하다고 확인되지 않았다.
- PhysioNet Holter rhythm code 0만 동율동으로 보고, 1 심방세동·2 조동·3 페이싱 및 미확인/그 외 값에는 HRV와 DC를 계산하지 않는다. 심방세동에서도 심박수 추정은 제공하나 필터가 심박 분포를 바꿀 수 있다.

## 검증과 사용 조건

합성 신호와 계산 예제는 자동 테스트로 검증한다. NeuroKit2 HRV 계산과 일부 수식을 비교하고, 제외 구간 연결·리듬 처리·데이터 누출을 점검한다. 환자별 참고 SDNN/SDANN/RMSSD/pNN50과의 차이는 노트북에서 정답 없이 요약한다. 이 참고값의 원래 처리법과 구간이 반드시 일치하는 것은 아니며, 일치 여부만으로 박동 검출이나 정상박동 분류의 정확도를 증명할 수 없다. 수동 또는 참조 주석을 활용한 박동 검출 검증, 필터/누락의 영향 평가, DC 별도 검증이 남아 있다.

사용자의 기존 `run_live` 설정은 유지하지만, 새로운 특징은 검증 전이므로 별도 `clinical.method_validation_confirmed` 설정이 false일 때 호출을 중단한다. 검증 결과를 검토한 뒤에만 이를 변경한다. 20명 파일럿은 실행과 비용 확인용이며 성능 결론에 사용하지 않는다. 전체 개발 데이터 분석도 같은 환자 집합끼리 비교하고 결측 및 실패를 보고해야 한다. 민감도 0.8에서의 특이도는 같은 표본에서 선택한 기술 통계이므로 독립된 일반화 성능으로 취급하지 않는다.

현재 일치하는 DL 5-fold 파일, 같은 환자의 DL/Pro-BNP 예측, 임상 27개 매칭 데이터가 확인되지 않아 로지스틱 OOF 및 짝지은 성능 비교와 임상 변수 결합 실험은 아직 구현·수행하지 않았다. 없는 fold를 임의로 만들지 않는다. test 결과를 보고 지표나 프롬프트를 조정하지 않는다.

## 출처

- [MUSIC 공개 데이터 및 문서](https://physionet.org/content/music-sudden-cardiac-death/1.0.1/), 데이터 버전 1.0.1; `subject-info.csv`와 `subject-info_codes.csv`의 Holter 리듬 및 HRV 항목.
- [ESC/NASPE HRV Task Force, 1996](https://pubmed.ncbi.nlm.nih.gov/8598068/): 시간 영역 HRV의 정의와 해석.
- [Campana et al., PRSA 적용 연구, 2010](https://pmc.ncbi.nlm.nih.gov/articles/PMC2886688/): RR 구간에서의 PRSA 및 감속능 산출. 이 구현이 Bauer 2006 절차와 완전히 같다는 뜻은 아니다.

## 2026-11-02 검증 결과

- YAML의 seed 42로 선택한 개발 원본 20명(동율동 15명, 영구 심방세동 5명): 20명 모두 특징 계산 성공. test·증강본과 API 호출은 사용하지 않았다. 기존 캐시를 재사용했다.
- 동율동 15명의 PhysioNet 참고값과 절대 차이의 중앙값 / 최대값: SDNN 0.78 / 46.70 ms, SDANN 1.49 / 11.97 ms, RMSSD 3.76 / 31.95 ms, pNN50 1.08 / 14.97 %p. 참고값의 원래 전처리와 구간이 다를 수 있어 오차를 알고리즘만의 오류로 단정할 수 없다. 동율동 중 제거 RR 비율의 중앙값은 2.8%, 최대값은 77.7%였다. 신뢰 저하로 판정할 임계값은 미리 정해지지 않았다.
- 별도의 [MIT-BIH Arrhythmia Database](https://physionet.org/content/mitdb/1.0.0/) 기록 100, 105, 200, 207에 대해 200 Hz 변환과 0.5–40 Hz 필터를 적용하고 품질 제외 없이 두 유도에서 검출했다. 주석과 100 ms 이내에서 순차적으로 짝지은 R파 민감도는 각각 99.91%, 99.14%, 99.81%, 98.81%; 정밀도는 각각 100%, 99.22%, 99.46%, 96.26%였다. 선택한 4개 기록에서의 탐색적 결과이며 MUSIC 환자의 검출 정확도를 입증하지 않는다.
- 같은 벤치마크에서 매칭된 연속 박동만 대상으로 주석이 양쪽 모두 `N`인 간격을 기준으로 보았을 때, 200번 기록은 RR 필터가 받아들인 975개 중 135개(13.8%)가 이 기준의 NN이 아니었다. `N` 이외 주석이 모두 조기수축인 것은 아니며 이 비교는 완전한 임상 NN 분류 평가가 아니다. 그러나 RR 변화만으로 정상박동 여부를 확인할 수 없다는 한계를 보여준다. 재현: `PYTHONPATH=. Global/.venv/bin/python Members/sang/experiments/monorouter_holter/validate_public_rpeaks.py` (공개 데이터 네트워크 접근 필요).
- 결론: 계산과 시범 R파 검출은 확인했으나 MUSIC의 정상박동 분류와 DC는 검증되지 않았고 합격 기준도 정해지지 않았다. `method_validation_confirmed`는 false로 유지한다. 전문 판독 또는 검증된 박동별 주석을 통한 R파·박동 종류 평가와 제외율이 높은 기록의 처리 기준이 필요하다.
