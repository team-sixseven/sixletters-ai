# LLM 전체 445명 실행 결과 (2026-11-04)

Furiosa 서버의 LLM 4종과 외부 API LLM 2종(Claude Haiku 5.5, GPT-6.1-Terra)을 원본 환자 전체 445명(train 285 + validation 71 + test 89, 양성 50명)에 실행한 결과다. 모두 미세조정 없는 zero-shot 추론이다. 점수는 보정된 위험 확률이 아니며 연구용이다. 환자별 예측과 원본 결과 폴더는 Git에 올리지 않는다(`results/llm_full445_20261104/`, `results/furiosa_all445_20261104/`).

집계는 [`scripts/summarize_llm_full445.py`](../scripts/summarize_llm_full445.py)로 만들었고, 성공한 응답만 사용한다. 지표는 AUROC / AP이며 혼동행렬 기준 문턱값은 0.5다.

## 실행 조건

- **Furiosa (std3 서버, RNGD NPU):** Qwen3-32B-FP8, Qwen3-30B-A3B-Instruct-2507-FP8, EXAONE-4.0-32B-FP8은 NPU 4장, GPT-OSS-20B는 NPU 1장. temperature 0, 최대 1024 토큰, JSON 스키마 출력. 445명을 환자 단위 층화 5-fold(seed 42, fold마다 89명·양성 10명)로 나누고, 사례 조건은 다른 fold에서 임상 거리가 가까운 양성·음성 각 2명을 골랐다. 입력 구성은 [`furiosa/furiosa_llm_compare/`](../furiosa/furiosa_llm_compare/)의 `--cohort all`이다.
- **Terra:** `gpt-6.1-terra`, 출력 토큰 1024, reasoning low. 모델이 값을 `null`로 답하거나 범위를 벗어나면 같은 요청을 최대 3회 시도한다(`max_attempts`). 이전 356명 결과(재시도 없음, 78건 실패)와 프로토콜이 다르다.
- **Haiku:** `~anthropic/claude-haiku-5-5`, 출력 토큰 1024, reasoning low, 재시도 없음.

## 읽을 때 주의할 점

- **Haiku는 미완료다.** 445명 중 384명까지만 호출했고 성공은 369건이다(실패 15건: 응답 형식 10, 시간 초과 4, HTTP 402 1). 384번째 환자에서 MonoRouter API가 결제·크레딧 오류(HTTP 402)를 반환해 노트북이 나머지 61명을 호출하지 않고 중단했다. 위 Haiku 수치는 성공한 369명(test는 79명) 기준이며 전체 결과로 해석하면 안 된다.
- **Terra는 22건(5%)이 실패했다.** 재시도 3회 이후에도 값을 주지 않은 경우다. 성공 423명 기준 수치다.
- **이전 356명 결과와 직접 비교할 수 없다.** 이번에는 test 89명을 포함해 fold와 사례 선택을 445명으로 새로 만들었다. 같은 모델·조건이라도 값이 달라진다(예: Qwen3-32B 임상 단독 AUROC 0.759 → 0.731).
- **순위 지표와 0.5 기준 분류 성능은 다르다.** 대부분의 모델·조건이 0.5 기준에서 양성을 거의 찾지 못한다(TP 0~5).
- **fold별·조건별 변동이 크다.** 양성이 50명(test는 10명)뿐이므로 소수점 둘째 자리 차이는 의미가 없다.
