# GPT-6-luna Holter 개발 데이터 추론 결과

## 실험 조건

- 기존 MUSIC Holter 원본 개발 환자 356명(train 285명, validation 71명). test 89명과 증강본은 사용하지 않았다.
- 모델: MonoGPT MonoRouter `~openai/gpt-6-luna`. 예비 실험에서 같은 입력·설정으로 성공한 20건은 대조 후 재사용하고 나머지를 새로 요청했다.
- 1차 실행은 353/356건 성공했고, 응답 검증 실패 3건을 각각 한 번 재시도하여 356/356건을 확보했다. 재시도는 같은 요청 방식이며 실패 이력은 로컬 `retry_audit.jsonl`에 남겼다.
- 입력은 전체 가용 파형에서 추정한 심박수·RR 기반 HRV·감속 능력과 품질 정보다. 정상박동의 정확한 분류와 DC는 검증되지 않았다. 정답과 환자 ID는 API에 보내지 않았다.
- 개발 데이터이고, 모델 선정에도 일부 예비 데이터가 사용됐다. 독립 test 성능이 아니며 임상적 진단 목적으로 사용할 수 없다.

## 성능

| 항목 | 값 |
|---|---:|
| 환자 수 | 356 |
| 실제 양성 / 음성 | 40 / 316 |
| AUROC | 0.4801 |
| AP | 0.1099 |
| 정확도 (위험도 50% 기준) | 88.76% |
| 민감도 (50% 기준) | 0.00% |
| 특이도 (50% 기준) | 100.00% |

모델의 출력 위험도 범위는 0~5%였다. 그래서 50% 기준에서는 전원을 음성으로 분류했다. 데이터의 음성 비율만큼 정확도가 높게 나타났으며, 양성 판별에 성공했다는 뜻이 아니다. AUROC와 AP도 이 개발 데이터에서 낮게 나타났으며, 모델 선정과 입력 지표 검증 상태를 감안해야 한다.

같은 356명의 결과에서 민감도 80% 이상을 만족하는 기준점을 사후 선택하면 기준 위험도 0.5%, 민감도 87.5%, 특이도 약 9.81%다. 이는 동일 데이터에서 기준점을 고른 기술 통계이며 독립 검증된 성능이나 확정된 임계값이 아니다.
