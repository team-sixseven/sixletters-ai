# Holter 파형 탐색과 QT 후보 확인

> **현재 화면은 30초 단위로 변경되었습니다.** 아래 10초 관련 내용은 이전 버전의 검증 기록입니다. 새 실행 조건과 결과는 [30초 Furiosa 실험](holter_30s_furiosa_20261103.md)을 참고하세요.

## 실행

저장소 루트에서 다음 명령을 실행하고 브라우저에서 `http://127.0.0.1:8765/`를 연다.

```bash
Global/.venv/bin/python Members/sang/experiments/holter_viewer/server.py
```

로컬 전용 읽기 서버이며 중지하려면 실행 터미널에서 Ctrl+C를 누른다. 기존 `basic.yaml`이 가리키는 환자 분할, NPY, 유도 메타데이터와 품질 CSV를 읽고 원본을 수정하지 않는다. 200Hz의 실제 X/Y/Z NPY를 메모리 맵으로 읽는다. 유도 Z가 없으면 선택할 수 없다. 샘플링은 원본 설정을 따른다. 표준 II 유도라고 가정하지 않는다. 445명은 split의 원본 파일이며 label은 화면에 표시하지 않는다. 필요 시 test 포함 여부에 주의한다.

## 화면과 제한

- 환자·측정 유도를 선택하고 숫자, 슬라이더, 품질 개요 또는 10초 이동 버튼으로 위치를 바꾼다.
- 기록 시작 절대 시각이 이 화면의 입력에서 확인되지 않아 상대 시간을 사용한다.
- 10초는 2,000개 원본 샘플이며 세로축은 원본값과 창별 자동 범위다. 사용자 제공 데이터의 의학적 단위나 표준 유도 변환을 임의로 확정하지 않는다.
- 30초 품질 CSV의 exclude를 전체 개요와 파형 배경에 표시한다. 제외 표시는 잡음/데이터 품질 상태이며 SCD 위험 여부가 아니다. 부분 마지막 구간이나 누락된 품질 행은 미확인으로 표시한다.
- 기존 LLM의 출력은 환자 단위 점수로 구간별 모델 위험도나 시간 좌표가 없으므로 자동 위험 구간·SHAP·QT 연장이라고 표시하지 않는다. 과거 ECG DL의 attention pooling도 해당 구간이 SCD 근거임을 입증하지 않으므로 그대로 위험으로 표시하지 않는다.
- 외부 서버나 LLM 호출은 하지 않는다. 로컬 호스트에서만 실행하고 접근기록에 환자 ID·신호를 남기지 않는다. 화면 데이터는 캐시하지 않도록 응답한다.

## QT 가능성 검토

NeuroKit2 0.2.13의 `ecg_clean`, `ecg_peaks`, `ecg_delineate(method="dwt")`를 이용해 연구용 QRS 시작 및 T파 끝 **후보**를 10초 구간에서 계산하는 코드를 마련했다. 품질 제외·미확인 구간에서는 계산을 중단하고, QT 보정(QTc), 연장 판정, SCD 위험, 알림을 만들지 않는다. [NeuroKit 공식 ECG 문서](https://neuropsychology.github.io/NeuroKit/functions/ecg.html)는 형태 변화 등에 따라 경계 검출이 부정확할 수 있음을 설명한다.

**기본 실행에서 QT 기능은 꺼져 있다.** 실제 적용 전 공개 QTDB 한 구간으로 탐색 검증을 했는데 오차가 커 자동 QT 표시를 기본 제공하기에 부적합했다. 필요할 때만 연구용 `--experimental-qt` 옵션으로 켜서 확인할 수 있고, 모든 출력은 미검증 후보이다. 아래 결과는 옵션 활성화의 임상적 타당성을 뜻하지 않는다.

- 공개 [PhysioNet QT Database](https://physionet.org/content/qtdb/1.0.0/) `sel100`의 첫 유도 10초, 250Hz를 200Hz로 재표본화, `q1c` 수동 경계 주석을 사용했다.
- 단순 매칭으로 주석 박동 10개 중 R 위치가 150ms 안에 매칭된 8개에서 QT 절대 오차 중앙값 **158ms**, 최대 **242ms**였다. 미매칭 2개는 오차 계산에 포함되지 않았다.
- 이는 단일 구간만 확인한 탐색 검증이다. 전체 모델의 일반화 성능을 추정할 수 없으며 우리 XYZ 환자 데이터의 정확성을 검증한 것도 아니다. `check_qtdb.py`로 재확인한다.

## 확인한 검증

- 저장소 파형 파일을 대상으로 시작·30초 경계·마지막 10초에서 API 반환 2,000개 값이 NPY 원본과 정확히 일치함을 확인했다.
- 품질 CSV의 제외 행과 해당 화면 구간이 일치함을 확인했다. 미검증 QT API는 기본 모드에서 HTTP 403으로 차단된다.
- 유효하지 않은 음수 시각과 경로 우회 입력을 거부하는 것을 확인했다.
- Windows Chrome headless에서 페이지의 기록 선택, 전체 개요, 실제 파형 첫 화면이 출력되는 것을 확인했다. JavaScript 구문과 Python 컴파일 검사도 통과했다. 브라우저 모든 조작·장시간 안정성은 추가 검증이 필요하다.
