# Qwen3-32B 개발 환자 356명 5-fold 사례 비교

## 실험 설계

사용자가 지정한 `Members/sang/datas/clincal/clinical_clean.csv`, `final_split.csv`와 검증된 기존 Holter 특징 캐시를 사용했다. 기존 train 285명과 validation 71명 총 356명(양성 40, 음성 316)을 합쳐 환자 단위 StratifiedKFold 5회, shuffle, seed 42로 나눴다. 각 평가 fold는 71~72명이며 양성은 각 8명이다. 기존 test 89명은 사용하지 않았다. 이번 fold는 기존 DL 모델의 fold와 다르며, 이전에 확인된 개발 데이터이므로 독립 외부 검증이 아니다.

각 fold마다 나머지 4개 fold로 임상 23개 변수의 평균·표준편차를 적합하고, 표준화된 임상 거리 기준 가까운 사례를 양성·음성 각각 2명씩 선택했다. 평가 fold 및 예측 환자 본인은 사례와 스케일러에 포함되지 않는다. 사례 구성은 결과별 균형을 맞추므로 실제 발생률을 대표하지 않는다. Holter의 RR·HRV 등은 원본 전체 기록에 대해 이전 계산 후 검증된 캐시를 사용했다. 정상박동 판정과 임상 변수의 시간적 가용성은 확인되지 않았다.

Qwen3-32B-FP8 스냅샷 `b33946f6cba6502114f12603c6caa4529cf396df`, Furiosa RNGD 4장, furiosa-llm 2026.4.0, temperature 0, thinking off, JSON schema로 세 조건을 356명씩 실행했다. 임상 전용 fold 분리 검증과 1,424개 사례의 실제 출처·라벨을 독립 검증했고, 모델 요청에서 예측 환자 ID·정답 및 fold 정보가 제외되는지 확인했다. NPU 요청 총 1,068/1,068건이 정상 종료하고 응답 범위·형식을 통과했다.

## 결과

0.5 고정 임계값, 혼동행렬 `[[TN, FP], [FN, TP]]`.

| 입력 | AUROC | AP | 민감도 | 특이도 | 혼동행렬 |
|---|---:|---:|---:|---:|---|
| Holter | 0.4835 | 0.1066 | 1/40 | 279/316 | [[279,37],[39,1]] |
| Holter + 임상 | 0.6915 | 0.2072 | 4/40 | 302/316 | [[302,14],[36,4]] |
| Holter + 임상 + 사례 | 0.6987 | 0.2670 | 3/40 | 314/316 | [[314,2],[37,3]] |

Fold별 AUROC는 Holter `[0.370,0.601,0.497,0.403,0.551]`, 임상 추가 `[0.685,0.866,0.585,0.587,0.732]`, 사례 추가 `[0.730,0.846,0.540,0.631,0.749]`로 변동이 있다. 최종 예측을 고정한 환자 단위 3,000회 paired bootstrap(seed 42)의 사례 추가 대 임상만 AUROC 차이 95% 분위 구간은 `[-0.0528, 0.0639]`였다. 이는 사례 선택과 fold 생성을 다시 수행하는 불확실성을 포함하지 않으며, 사례 추가가 AUROC를 개선한다고 확정할 수 없다.

고정 0.5에서 양성 대부분을 놓쳤다. 순위 지표와 정답 분류 성능은 다르며, 점수는 보정된 위험 확률이나 임상 판단 근거가 아니다. 설정 선택에 개발 데이터와 이전 validation을 사용했으므로, 성능 확정을 위해 독립된 환자 집단과 시간적 입력 가용성 검증이 필요하다.
