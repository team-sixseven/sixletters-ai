# Furiosa LLM 전 모델 임계값 비교

## 조건과 해석

기존 Qwen3-32B 및 추가 세 모델의 기존 예측값을 사용했다. 개발 환자 356명 중 양성 40명, 음성 316명이며 모델·입력 조건마다 같은 환자다. 예측 점수 이상(`>=`)을 양성으로 분류했다. 0~100의 출력값을 비율로 변환했으며 표에는 %로 표시했다. 이전 50% 결과의 혼동행렬 16개 모두와 일치함을 확인했다. 원본 test 89명은 이 비교에 사용하지 않았다.

**중요:** 표의 수치는 검증된 SCD 발생 확률이나 임상 기준이 아닌 LLM 출력 점수다. 양성예측도(PPV)는 이 자료의 양성 비율에 의존하므로 실제 병원 환자군에 그대로 적용할 수 없다. SCD 진단·시술 기준으로 사용하지 않는다.

## 주요 관찰

- 목표 민감도 80% 이상에서 EXAONE의 Holter+임상 조건은 점수 42.5% 이상에서 33/40명을 탐지하고 120/316명을 위양성으로 분류했다. 이 탐색 자료에서 위양성 수가 가장 적었다.
- 같은 조건에서 90% 이상을 얻으려면 점수 기준이 12.5%로 내려가며 40/40명 탐지, 313/316명 위양성이다. 동점이 많아 기준을 조금 움직였을 때 분류 인원이 크게 바뀐다.
- 기존 Qwen3-32B의 임상 단독 조건은 목표 90%에서 36/40명 탐지 및 209/316명 위양성이다. 대상자로 표시된 245명 중 실제 양성은 36명으로 PPV 14.7%다.
- 점수 기준 0% 또는 모든 환자가 양성으로 분류되는 조건의 민감도 100%는 환자를 구분한 성능을 의미하지 않는다.
- 모든 모델의 모든 조건에서 목표 80% 기준을 이 데이터에서 사후 선택한 결과이므로 가장 좋은 조합도 별도 환자에게 적용해 확인해야 한다. 추가 검사량과 놓친 환자의 부담을 임상의와 함께 정한 뒤 독립 데이터 및 보정된 예측으로 검증한다.

## 예측 점수 분포

![모델과 입력 조건별 실제 양성·음성의 예측 점수 분포](../results/furiosa_llm_compare/score_distributions_20261103.png)

각 행은 모델, 각 열은 입력 조건이며, 파란색은 실제 음성 316명, 빨간색은 실제 양성 40명이다. 가로축은 모델의 점수, 세로축은 각 집단에서 해당 점수 구간에 속하는 비율이다. 집단 크기가 달라 각각의 집단을 100%로 정규화했으므로 막대 높이를 전체 환자 수로 해석하지 않는다. 5%p 간격의 구간을 사용하고, 100% 점수는 마지막 구간에 포함한다. 점선은 50% 기준이다.

여러 조건에서 특정 점수 구간에 양성과 음성이 함께 몰려 있다. 이런 경우 기준을 조금만 바꿔도 한 번에 많은 환자의 판정이 바뀔 수 있다. 그래프는 점수 분포를 보여주며, 검증된 실제 SCD 발생 확률을 보여주는 것은 아니다.

분포도 생성 코드: `Members/sang/furiosa/furiosa_llm_compare/plot_score_distributions.py`. 16개 그래프에서 환자 일치, 양성 40명·음성 316명의 구간 합계, 50% 이상 TP/FP가 기존 집계와 같은지 확인했다. 환자별 예측값은 서버 밖으로 내보내지 않았다.
