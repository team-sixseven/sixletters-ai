# RunPod 60개 trial 파라미터 전체

Optuna trial별 실제 `resolved_config.yaml`과 `optuna_trials.csv`를 대조했다. 각 조합 10개, 총 60개. 표의 실수는 읽기 쉽도록 유효숫자 5자리로 반올림했고 원래 정밀도는 [전체 CSV](../results/runpod_tcn_20261101/60개_trial_파라미터_전체.csv)와 각 설정 파일에 있다.

공통: Adam, 최대 100 epoch, patience 10, 개선 최소값 0.0001, seed 42, 환자당 최대 128개 30초 구간. batch/workers는 첫 TCN + Transformer의 trial 000~007만 1/0, 나머지는 6/4다. 상세 데이터와 중단 조건은 [기존 결과 보고서](runpod_ecg_60_experiments_20261101.md) 참조.

표 설명: LR=학습률, WD=weight decay, 분류기=분류기 dropout, 시퀀스=시퀀스 모델 dropout, TCN=hidden dimension / kernel size, 층=Transformer encoder 층 수, AP=validation average precision. LSTM의 recurrent layer는 코드 기본값 1개. AP는 validation에서 계산했고 독립 test가 아니다.
