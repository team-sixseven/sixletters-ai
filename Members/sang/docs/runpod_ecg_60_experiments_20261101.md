# Runpod Holter ECG 딥러닝 60개 실험 결과

- 실험 기간: 2026-11-01~2026-11-02 (한국 시간). 완료된 trial의 기록상 시작 11-01 17:35, 마지막 종료 11-02 03:59.
- 범위: 6개 모델 조합 × 조합별 10 trial. 총 **60개 학습 완료**. 세부 기록은 아래 trial 표와 로컬 결과에 있다.
- **최종 test 평가는 수행하지 않았다.** 60 epoch 이상 학습한 trial이 없어 사전에 합의한 조건에 따라 6개 조합 모두 test를 보류했다.
- 각 조합의 최고 validation AP 실험 1개씩은 로컬에 보관하고 MLflow에 기록했다. 이는 test 대상 확정이나 독립 성능 검증을 뜻하지 않는다.

## 실험 과정과 데이터

1. Runpod의 NVIDIA A100 80GB PCIe 환경을 확인하고, 지정된 `Members/sang/datas/Holter/windows`에서 split에 포함된 파형 파일과 품질·유도 메타데이터를 전송했다.
2. 기존 `final_split_augmented.csv`를 그대로 사용했다. 아래는 **기록 수**다. 학습 기록에는 원본 환자와 그 증강 기록이 포함되므로 349를 독립 환자 수로 해석하면 안 된다.

| 분할 | 기록 수 | 양성 | 음성 |
|---|---:|---:|---:|
| Train | 349 | 96 | 253 |
| Validation | 71 | 8 | 63 |
| Test | 89 | 10 | 79 |
| 합계 | 509 | 114 | 395 |

3. 파형은 200 Hz, 30초(6,000 samples) 단위로 처리했다. `segment_rpeaks.csv`의 제외 정보를 적용하고, 사용 가능한 구간에서 기록당 최대 128개를 시간순으로 선택했다. 유도 메타데이터로 미측정 Z 유도를 제외했다. 추가 정규화는 `none`이다.
4. 공통 구조는 공유 단일 유도 CNN → 측정 유도 특징 평균 → 시퀀스 모델 → masked attention MIL → 분류기다. 학습 양성 가중치는 train 기록의 음성/양성인 253/96 ≈ 2.6354다.
5. Optuna TPE로 설정을 탐색했다. 최대 100 epoch, early stopping patience 10, 최소 개선량 0.0001이며, **각 trial은 validation loss가 직전 최적값보다 0.0001 넘게 개선될 때 checkpoint를 저장**했다. 조합 내 trial은 그 checkpoint의 validation AP로 비교했다. 이 두 선택 기준은 다르다.
6. 처음 TCN + Transformer 조합의 trial 000~007은 batch size 1 / worker 0으로 학습했다. 진행 중 처리량을 개선하기 위해 **trial 008부터 모든 조합에 batch size 6 / worker 4**를 적용했다. 설정 차이는 trial 표에 명시했으며 동일한 배치 조건의 완전 통제 비교는 아니다.
7. 6개 조합을 모두 학습한 후 60 epoch 이상 도달한 후보가 없음을 확인해 test를 보류했다. MLflow에는 조합별 validation AP 최고 모델 6개와 집계 지표를 기록했다. 환자별 예측과 audit은 MLflow 업로드 대상에 포함하지 않았다.

## 해석과 제한

- 검증셋의 양성은 8명이라 한 명의 예측 변화가 재현율을 12.5%p 바꾼다. 지표의 불확실성이 크며, 단일 split 결과를 일반화 성능으로 단정할 수 없다.
- 본 보고서는 모델 탐색과 checkpoint 선택에 사용한 validation 결과다. 같은 validation 성능으로 최종 모델·기준값을 선택하면 낙관적일 수 있고, 재사용된 test가 있다면 독립적인 최종 검증으로 간주할 수 없다.
- 60 epoch 조건은 학습 시간에 관한 조건이지 모델 성능을 보장하지 않는다. 이 조건 때문에 test가 보류됐으며, 성능이 높은 trial도 모두 test 평가 자격을 얻지 못했다.
- 예를 들어 ResNet + Attention LSTM FCN trial 003의 validation에서 기준값을 0.5에서 0.4로 낮추면 양성 8명 중 4명을 탐지하고 음성 63명 중 5명을 잘못 양성으로 판정한다. 이는 **탐색적 validation 예시**이며, 기준값을 사후 선택한 성능이나 test 결과가 아니다.
- 전체 학습에는 원본과 증강 train 기록이 함께 쓰였으며 class weight도 기록 수 기준이다. 다른 환자 단위 연구와 비교할 때 이 차이를 고려한다. 본 실험은 ECG 단독이며 임상변수 결합 모델이 아니다.
- A100 80GB, Python 3.12, PyTorch 2.8.0+cu128, NumPy 2.5.2, pandas 2.3.3, scikit-learn 1.9.1 환경에서 실행했다. batch 변경 전후는 직접적인 속도·성능 통제 비교가 아니다.
