선택한 30초 원본 파형

세로축은 NPY 원본값이며 화면 높이에 맞춰 자동 조정됩니다. 유도 X/Y/Z는 표준 12유도로 변환한 값이 아닙니다.

기본적으로 비활성화됩니다. 공개 QT 주석 데이터의 단일 10초 구간에서 대조한 8개 박동의 QT 오차 중앙값이 158ms로 커서 판정에 사용할 수 없습니다. 연구용 실행 옵션으로만 활성화할 수 있습니다.

선택한 30초 구간의 Furiosa 실험

실제 원본 파형에서 R파·RR 요약을 계산해 NPU 모델에 전달한 시험입니다. LLM은 파형 이미지나 T파를 직접 보지 않습니다. 점수는 검증되지 않은 검토 우선순위이며 SCD 위험 확률, QT 연장 판정, 알림 기준이 아닙니다. 선택한 한 구간에만 해당합니다.
